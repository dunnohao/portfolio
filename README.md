# dunno_hao | Photography Portfolio

Welcome to the digital portfolio of **dunno_hao**, a live music and concert photographer. 

This repository serves the static website frontend for the portfolio spanning numerous festivals, live venues, and exclusive portrait sessions.

## Aesthetics
The project leverages a custom-built pure dark glassmorphic design and structural CSS Grid masonry components to deliver maximum emphasis on high-contrast stage lights and photographic emotion. All photography respects its color grading with zero external CSS filters attached.
